# Charlie's Daily Gaming Pack

Personalized daily gaming news digest, published automatically to GitHub Pages.

**Live app:** https://taylor-player-news.github.io/taylor-daily-player-news/

## What's here
- `index.html` — the digest UI (installable as a home-screen web app via `manifest.json` + `sw.js`).
- `images/` — real, downloaded (not AI-generated) press images, resized/compressed for mobile.
